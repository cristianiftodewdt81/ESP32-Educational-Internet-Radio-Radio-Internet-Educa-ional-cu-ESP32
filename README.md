# ESP32-Educational-Internet-Radio-Radio-Internet-Educa-ional-cu-ESP32
This project is primarily an **educational tool** designed to explore and understand the fundamentals of: - **Digital to Analog Converters (DAC)** and hardware audio decoding. - **Audio Streaming** over WiFi using microcontrollers. - **Hardware Integration** (SPI, I2S, I2C buses).
